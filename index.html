Learner-directed agentic coding

Create with AI.
Keep thinking in charge.

Agentic Coding Studio is a learning environment where young people create games, stories, and apps with an AI coding agent. Learners set the goal, review the work, test it, and decide what changes next.

What participation looks like

Young people make the choices.

A learner might imagine a game, explain the idea to the coding agent, review its plan, and try what it builds. When something misses the mark, the learner tests, gives clearer feedback, and revises the project.

Start with an idea

Choose a personally meaningful game, story, simulation, app, or other computational project.

Work with the agent

Explain the goal, review the proposed plan, and decide whether the approach makes sense.

Test and improve

Run the project, notice what does not work as intended, and guide the next revision.

The learning cycle

Young people direct the process, not just the prompt.

Creation becomes a cycle of intention, review, evidence, and revision.

  1. Choose a goal
  2. Make a clear request
  3. Review the agent’s plan
  4. Build or revise
  5. Run and test
  6. Give feedback
  7. Reflect

What learners practice

More than getting code to run.

Learner-directed coding

03

Learning through creation

Games, stories, simulations, and apps give ideas a form that can be shared, tested, and improved.

Why now

As code production changes, computational thinking still matters.

When AI agents take on more mechanical production, people need to be better at specifying intent, decomposing problems, setting constraints, evaluating outputs, testing behavior, and revising systems toward meaningful goals.

Agentic Coding Studio does not treat AI as an answer machine or a replacement for thinking. It studies how learners can work with AI while retaining responsibility for what they make and why.
