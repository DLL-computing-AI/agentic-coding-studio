About the project

Thinking changes when coding changes.

AI coding agents can help turn an idea into a working project. Young people still need to decide what to make, whether it works, and how it should improve.

Why this project

From producing syntax to directing systems.

AI coding agents can interpret goals described in everyday language, suggest a plan, generate and debug code, create project assets, and run tests.

That changes where the hard—and valuable—thinking happens. Learners spend less time overcoming syntax and more time making goals clear, breaking problems into parts, checking results, debugging, and revising.

Learners should work with AI without handing over responsibility for their goals, decisions, quality, interpretation, testing, or revision.

The questions that matter

Thinking stays with the learner.

The agent can help produce code, but it cannot decide what matters to the learner or what a successful project should be.

  • What should the project do?
  • What are the component parts of the problem?
  • What counts as success?
  • Does the agent’s plan make sense?
  • Does the project behave as intended?
  • What needs to change next?

Computational agency

Intentional, critical, creative action.

Computational agency is learners’ capacity to use computational tools, including AI systems, to pursue meaningful goals, make design choices, evaluate outcomes, and revise their work based on evidence, feedback, and audience needs.

Agentic Coding Studio is grounded in learner-directed, project-based creation. Youth create personally meaningful computational artifacts rather than passively consuming AI-generated answers.
